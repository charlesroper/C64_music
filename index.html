Reverse-engineered engine architecture

              

                

                  1. Multi-Speed Fractional Raster Clock (Refsp
                    / CREFSP):
                  In wizball.asm and gameover.asm, DREFRESH
                  waits for raster lines 32, 110, 188 and 266. arkanoid.asm uses 57,
                  117, 172 and 237. Those lines stay below 263, so Arkanoid's waits work on both PAL
                  and NTSC frames. At each raster point, the 16-bit Refsp value is
                  added to CREFSP. When the high byte CREFSP+1 changes,
                  REFRESH
                  runs. Thus $0100 gives 200Hz,
                  $0080
                  gives 100Hz and $0040 gives 50Hz.
                

                

                  2. Bytecode virtual machine (vt0..vt2):
                  Each SID channel has a 16-bit sequence pointer. arkanoid.asm and
                  gameover.asm
                  place PC0..PC2 at $10..$15.
                  wizball.asm
                  uses $04..$09, greenberet.asm
                  uses A0..A2 at $16..$1B and rambload.asm
                  uses Z0..Z5 at $10..$15. Bytes below
                  $C0
                  are note numbers. Values $60 and above select an immediate duration
                  byte rather than a datablock lookup. Bytes
                  >= $C0
                  (COM) dispatch through
                  vt0..vt2
                  for loops (For/Next), subroutine calls (Call/Ret/CT), instrument loads (FLoad/Vlm/Freq), filter sweeps (Filter/Master) and
                  inline 6502 machine code hooks (Code).
                

                

                  3. Real-time $D418 digi-drums (arkadrum.asm
                    and gameover.asm):
                  While a 50Hz VIC-II raster interrupt runs the three SID channels and the drum
                  pattern sequencer (DRUMS), the foreground MAIN loop
                  continuously calls PLEY. It streams either real-time algorithmic
                  4-bit waveforms (arkadrum.asm) or packed 4-bit PCM rock drum samples
                  (ROCKBASS, ROCKSNARE and ROCKCOWBELL in
                  gameover.asm) to the 6581 master volume DAC at $D418.
                

                

                  4. Rambo II secret Morse code (rambload.asm):
                  One second into the loader music, the score runs
                  DFB Code: DFW STARTMC
                  and patches MUS+1 to
                  MCREFR. Voice 1 transmits the hidden string at Secret,
                  stored without spaces, in Morse code through the bit-packed lookup table
                  CodeTab. The carrier starts at $224B (516Hz PAL, 535Hz
                  NTSC). MCFC1 and MCFC2 step it down to
                  $1B38
                  (409Hz PAL, 425Hz NTSC) and $19B1 (386Hz PAL, 401Hz NTSC) before
                  REFRESH
                  is restored.
